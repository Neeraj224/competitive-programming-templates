# Competitive Programming Templates

This repository contains my **clean, reusable templates** for common problem-solving patterns used in competitive programming.

All templates are implemented in Python, with a focus on clarity, speed, and reusability during contests and interviews.

## Topics Covered

Fast I/O, Binary Search, Sliding Window, Two Pointers, DFS, BFS, Graph Traversals, Union Find, Segment Trees, Fenwick Trees, Recursion, Backtracking, Dynamic Programming
